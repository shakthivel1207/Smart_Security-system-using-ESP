Hardware Pin Allocations

  • GPIO 14 (Relay Output) Solenoid Door Lock Relay
  • GPIO 34 (Analog Input ADC) Footstep Force Sensor (FSM)
  • GPIO 5 (SPI SS / CS) MFRC522 RFID Chip Select
  • GPIO 22 (Digital Output) MFRC522 RFID Reset (RST)

SPI Bus & WiFi REST API

The MFRC522 RFID reader communicates via ESP32 SPI bus. The footstep sensor operates on ADC channel GPIO 34 (0-4095). WiFi REST API endpoints allow wireless control over IP (`/status`, `/unlock`, `/lockdown`).
